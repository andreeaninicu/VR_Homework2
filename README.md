# VR Basketball Homework2

A small VR basketball game built for Lab 2 – Introduction to Mixed Reality. Grab a ball, throw it at the hoop and score points. It can be played in the Unity editor without a headset, using the XR Device Simulator.

## Authors: Ninicu Andreea and Bianca-Mariana Barbu , 3E3
## Demo video: https://youtu.be/W7xW96flZd0

Tech stack
Unity 6 (6000.3 LTS)
OpenXR Plugin + XR Plugin Management
XR Interaction Toolkit 3.x (Starter Assets + XR Device Simulator samples)
Input System, TextMeshPro, Universal Render Pipeline
